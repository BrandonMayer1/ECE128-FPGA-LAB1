# ECE128-FPGA-LAB1

The purpose of this lab was to design and implement an 8-to-1 multiplexer. This was done by writing Verilog code in three different styles: structural, behavioral, and dataflow. In addition, a testbench and constraint files were created to simulate the data and map the pins to the board. An 8 to 1 Mux has 8 inputs (i0-i7), 1 output (O), and three selector lines (s0-s2). Different combinations of the selector lines decide which input line is the output.

Run Instructions,
1) Create a new project, selecting the board type you are uploading 2
2) Add the three design files under the design folder
3) Add the testbech under the simulation folder
4) Add the constraint files under the constraint folder
5) Run Synthesis
6) Run implementation
7) Run Generate Bitstream
8) Find device and program
